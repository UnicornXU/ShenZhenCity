# 深圳 · 山海之城

可在浏览器中旋转、缩放和浏览的深圳 3D 城市沙盘，使用 Three.js 构建，包含十区（含大鹏新区）的 16 处地标及建筑群、坂田片区，以及程序生成的楼宇街区、海湾、山体绿地、道路、桥梁、树木、船只和移动车流。

## 启动

需要 Node.js 22.12 或更高版本。

```powershell
cd E:\ChildrenGame\shenzhen-city
npm install
npm run dev
```

打开 http://127.0.0.1:5188 。生产构建使用 `npm run build`；使用 `npm run preview` 可预览 `dist`。

## 操作

- 鼠标拖动旋转、滚轮缩放、右键拖动平移；触屏单指旋转、双指缩放和平移。
- 点击左侧地标卡片、场景中的地标标签或地标建筑，即可进入特写和查看介绍。
- 城区筛选覆盖宝安、南山、福田、罗湖、龙岗、盐田、龙华、光明、坪山和大鹏。单独的“坂田”筛选可定位华为总部 F1 和天安云谷；“龙岗”也包含这两处模型。移动端筛选栏可横向滑动。
- 工具栏提供缩放、旋转、俯视、复位和 PNG 场景截图。
- 底栏可调节光照时间或选择日间、黄昏、夜景，开启或暂停地标自动漫游。
- 图层面板可控制建筑、道路车流、山体绿地和地标标签。
- “导出模型”生成完整的 `shenzhen-city.glb`，包含程序生成的几何和材质。导出不受图层隐藏状态影响，保留当前光照下的材质发光参数；灯光、交互标记、文字标签和背景地板不属于导出的模型。
- 键盘 Tab 可以访问按钮；聚焦画布后方向键平移。系统启用减少动态效果时，停止车辆和船只动画，并立即切换视角。

## 模型范围

现有 16 处地标均按公开建筑参考建模，保留各自可辨识的轮廓、结构与立面特征：

- 平安金融中心：切角收分塔身、银色外柱、幕墙分格、设备层和阶梯裙房。
- 中国华润大厦：纤细圆形塔身、56 根竖向肋、收拢的塔冠和交叉结构。
- 京基 100：圆角玻璃塔身、弧形收拢塔冠、外框和楼层线。
- 地王大厦：青绿色板式塔身、两端圆柱、分层塔冠和双天线。
- 深圳市民中心：连续蓝色曲面屋顶、黄色圆塔、红色方塔、玻璃翼楼与柱廊。
- 深圳湾体育中心：连续椭圆网壳、偏心屋顶开口、看台、球场及交叉格构。
- 深圳大运中心：开敞体育场、圆形体育馆、长方形游泳馆，细分的三角玻璃外壳、看台、跑道和水面。
- 深圳·红立方：沿狭长场地排列的四组倾斜红色体量、细密竖向板材、连续窗带和开放通道。
- 宝安机场 T3：流线主楼、十字指廊、蜂窝格构表皮、玻璃端面及登机桥。
- 深圳北站：上平下曲的悬挑屋盖、平行屋面肋、玻璃候车厅、轨道和站台雨棚。
- 光明文化艺术中心：白色庭院组团、临水拱形入口、金色内衬、竖向立面和屋顶庭院。
- 坪山大剧院：银色铝制表皮、深红剧场体量、室外上升步道、屋顶花园和通透入口。
- 大鹏所城南门：拱门、分层城墙、城垛、木构门楼、灰瓦翘檐及后方民居巷道。
- 盐田港：蓝色岸桥、桁架吊臂、拉索、集装箱堆场和靠泊货船。
- 坂田华为总部 F1：以华为公开的深圳坂田 F1 实景为参考，细化微凹玻璃立面、窗格、金属侧框和层叠檐口；附楼、水景、树阵为园区氛围示意。
- 坂田天安云谷：蓝灰玻璃塔楼组团、竖向边框、水平挑板、错落屋冠、绿化裙房、连廊和开放庭院。塔楼数量和位置经过压缩，并非园区总平面复刻。

这些模型是依据参考图像与建筑介绍制作的轻量化几何重建，不是实景扫描、建筑施工模型或逐尺寸复刻。幕墙和结构线经过批量合并，以控制绘制开销；低层场馆使用单独的特写方向，减少周边高楼和山体遮挡。

龙岗位于沙盘东北侧的新增内陆片区，包含城区标注、街区楼宇、绿地和连接道路。全部地标均支持城区筛选、点击定位、昼夜光照、自动漫游和 GLB 导出。地标数量和筛选选项从场景数据生成。

坂田位于龙岗中心片区以西，模型包含五和大道、坂雪岗大道和冲之大道三条示意道路，预留了道路和园区建筑之间的空间。扩展后的全景自动涵盖北部与东部新增区域。十区覆盖指每区代表性地标与周边场景；并非每个街道、每栋建筑的全量三维数据，暂不包含市域外的深汕特别合作区。

龙岗地标参考：[深圳大运中心介绍](https://www.sz.gov.cn/szzt2010/szwtt/wtcg/tycg/content/post_11129078.html)、[深圳·红立方介绍](https://www.sz.gov.cn/szzt2010/szwtt/wtcg/whcg/content/post_12374186.html)。

建筑形态参考：[KPF / 平安金融中心](https://www.kpf.com/project/ping-an-finance-centre)、[KPF / 中国华润大厦](https://www.kpf.com/news/exhibit-staged-in-shenzhens-latest-kpf-designed-tower)、[Farrells / 京基 100 项目资料](https://beltandroad.hktdc.com/sites/default/files/2021-11/TFP%20Farrells%20Project%20Presentations_English%20Version_0.pdf)、[CTBUH / 地王大厦](https://www.skyscrapercenter.com/build/shun-hing-square/258)、[深圳新闻网 / 市民中心](https://www.sznews.com/photo/content/mb/2018-05/28/content_19206231_2.htm)、[深圳市政府 / 深圳湾体育中心](https://www.sz.gov.cn/en_szgov/life/sports/content/post_1351427.html)、[gmp / 大运中心](https://www.gmp.de/en/projects/531/universiade-2011-sports-center)、[Mecanoo / 龙岗文化中心](https://www.mecanoo.nl/Projects/project/65/Three-Cultural-Centers-One-Book-Mall)。参考照片未作为模型纹理打包。

新增八组模型的来源、保留特征与简化边界见 [建筑参考说明](architecture-references.md)，应用内的详情卡也可直接打开相应建筑参考页面。

**这是艺术化、压缩比例的城市模型，不是深圳真实 GIS、测绘或导航模型。** 地标位置、建筑比例、道路拓扑、海岸线、山体与城区标注均为示意；其他建筑由固定随机种子生成。界面中的建筑和树木数量为场景对象统计，不代表深圳的城市统计。

所有资源均由本项目生成或 npm 打包；构建完成后，运行时无需地图服务、API Key、远程图片或 CDN。导出模型使用 glTF 的 GPU 实例化扩展以保留批量建筑和树木；导入软件应支持 `EXT_mesh_gpu_instancing`（或先转换实例）。

## 文件结构

- `src/data.js`：地标信息、示意坐标、固定随机种子。
- `src/city-layout.js`：扩展地形、海岸线、全景参数和坂田道路预留。
- `src/landmark-geometry.js`：几何批处理、截面放样、结构线和材质工具。
- `src/landmark-models.js`：原有八处地标的细化几何、幕墙、结构和场馆内部，以及全部模型的入口。
- `src/district-models.js`：新增六区及坂田八组模型的专用几何。
- `src/city.js`：几何建模、实例化渲染、镜头、灯光、拾取、导出。
- `src/main.js`：导航、筛选、地标详情、光照、图层、下载操作。
- `src/style.css`：桌面和移动端界面。

技术参考：[Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)、[Three.js GLTFExporter](https://threejs.org/docs/pages/GLTFExporter.html)。
